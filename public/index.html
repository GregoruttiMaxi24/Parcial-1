API RESTful

API de Componentes de PC y Periféricos

Backend hecho con Node.js, Express y MongoDB (Mongoose) para una tienda de componentes de computadora y periféricos. Parcial 1 de Aplicaciones Híbridas.

Categorías

CRUD de categorías de productos (procesadores, placas de video, periféricos, etc.).

Método Endpoint Descripción
GET /api/categorias Lista todas las categorías. Filtros: ?activa=true, búsqueda ?buscar=texto
GET /api/categorias/:id Obtiene una categoría por su id
POST /api/categorias Crea una categoría (body: nombre, descripcion, activa)
PUT /api/categorias/:id Actualiza una categoría existente
DELETE /api/categorias/:id Elimina una categoría

Productos

CRUD de productos, con filtros combinables y búsqueda por nombre.

Método Endpoint Descripción
GET /api/productos Lista todos los productos. Filtros: ?categoria=, ?marca=, ?destacado=true, ?enStock=true, ?precioMin=, ?precioMax=, búsqueda ?buscar=texto
GET /api/productos/:id Obtiene un producto por su id
POST /api/productos Crea un producto (body: nombre, precio, stock, marca, categoria, imagen, destacado)
PUT /api/productos/:id Actualiza un producto existente
DELETE /api/productos/:id Elimina un producto

Usuarios

Registro, login y administración de usuarios (no cuenta como una de las rutas principales del parcial).

Método Endpoint Descripción
POST /api/usuarios/registro Crea un usuario (body: nombre, email, password, rol)
POST /api/usuarios/login Inicia sesión (body: email, password)
GET /api/usuarios Lista usuarios. Filtros: ?rol=, búsqueda ?buscar=texto
GET /api/usuarios/:id Obtiene un usuario por su id
PUT /api/usuarios/:id Actualiza un usuario existente
DELETE /api/usuarios/:id Elimina un usuario
